GDACS (United Nations & European Commission)

Directly integrates the official Global Disaster Alert and Coordination System (UN OCHA / EC JRC). Ingests real live tropical cyclones (with storm name & speed), worldwide flood bulletins, and active forest fires.

USGS GeoJSON Worldwide Seismic Network

Connects directly to the United States Geological Survey global network. Retrieves verified magnitude, coordinates, hypocentral depth, and event timestamps for events across all continents and tectonic fault lines.

Open-Meteo Meteorological Modeling

Provides live atmospheric observation and forecast data. Used by our Python risk engine to calculate Estimated Flood Risk, Gale Wind speeds, and Extreme Heatwave conditions across global stations.

NASA FIRMS Active Fires (Configurable)

Designed for VIIRS/MODIS satellite thermal anomaly detection. If an API key is not configured in .env, it displays honest empty status: “Fire source not connected yet”.
